# Todo Outlook Planner

「区分」「タスク名」「納期」「進捗状況」「補足」「課題」を入力できるタスク表と、明日やること・Outlookカレンダー登録候補を自動整理するReactアプリです。

## 主な機能

- 区分、タスク名、納期、進捗状況、補足、課題、Outlook登録候補の入力・編集・削除
- 納期が明日までの未完了タスクを「明日やること」として自動抽出
- Outlook登録候補にチェックした未完了タスクから、予定作成画面へのリンクを生成

## 開発コマンド

```bash
npm install
npm run start
npm run build
```
